# 百年门第

一款可直接在浏览器游玩的中国古代世家模拟器。玩家从寒门、没落士族、退伍武官、商贾旁支或胥吏之家起步，在架空王朝中经营数百年的宗族传承。

## 核心系统

- 多代族谱：婚配、招赘、生育、宗子与家主继承
- 族人培养：自动按才分业，并支持世代筛选、分页与批量安排
- 科举仕途：同年限考一次，县试至殿试衔接九品至一品升黜
- 官员任地：本籍、外任、边任与京职各有收益风险，可请调并保留履历
- 官员治理：抚民、催科、兴学、治河、练兵与交际会改变考成和官灾
- 官场人脉：座师、同年、上官与地方士绅关系可经营，但每年只能交际一次
- 田庄产业：田亩、商铺、作坊、粮仓、宅院、藏书及浮动粮价交易
- 商队贸易：五条跨年商路、领队能力、官员照应、劫损与大行情共同决定回报
- 宗族建设：宗祠、族学、藏书楼、义庄与谱局
- 动态事件：灾荒、疾疫、械斗、党争、清丈、征役与改朝换代
- 长期存档：浏览器自动保存，并支持 JSON 导入、导出
