# 百年门第

一款可直接在浏览器游玩的中国古代世家模拟器。玩家从寒门、没落士族、退伍武官、商贾旁支或胥吏之家起步，在架空王朝中经营数百年的宗族传承。

## 核心系统

- 多代族谱：婚配、招赘、生育、宗子与家主继承
- 族人培养：读书、习武、务农、经商、掌家、行医与著述
- 科举仕途：县试、院试、乡试、会试、殿试及九品至一品升黜
- 田庄产业：田亩、商铺、作坊、粮仓、宅院与藏书
- 宗族建设：宗祠、族学、藏书楼、义庄与谱局
- 动态事件：灾荒、疾疫、械斗、党争、清丈、征役与改朝换代
- 长期存档：浏览器自动保存，并支持 JSON 导入、导出

## 游玩

[打开在线版](https://uo13.github.io/bainian-mendi-simulator/)

项目为纯前端静态页面，不需要服务器或数据库。科举、官阶、宗法与田庄等制度均经过游戏化处理，并非特定朝代的历史复原。
